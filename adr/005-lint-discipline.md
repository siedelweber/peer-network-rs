## Lint discipline · `sec:lint:record`

**Record (Lint discipline)** · `rec:lint:decision` Status: accepted. Scope: Compiler lints, source disciplines and the foundation gate. Depends on: (`rec:labels:decision`), (`rec:render:decision`), (`rec:output:decision`). Does not establish: A clean gate establishes no implementation of the paper.

**Setup (Context)** · `setup:lint:context` A rule without an executable check becomes dependent on reviewer memory.

**Decision (Policy)** · `dec:lint:policy` Workspace Rust and Clippy tables define the shared compiler policy and are inherited by every first-party member, including cli-common and execwrap. The nursery group is allowed in the required run and enabled as warnings in a separate advisory run, whose count does not determine the verdict. First-party code prohibits uncontrolled stdout printing, stderr printing and process exit. A first-party suppression is unconditional and names individual lints on the smallest item and carries a Justified comment with a complete sentence; tests and harnesses contain no suppressions. The former pack crates are maintained as first-party packages under AGPL-3.0-only and participate in all first-party checks. The sole vendored tree is the regular-expression engine, reviewed against its public fork commit with the documented scalar-alias substitutions (`rule:vendor:regexml`); its upstream manifest and Clippy policy are preserved. The vendored owner receives only well-formed-mint, unique-mint and local-resolution checks: its source comments cite its own document heads, so those checks require no first-party genre rules.

**Consequence (Tradeoffs)** · `cor:lint:tradeoffs` The formatter controls layout. The first-party width is 130, including both former pack crates. Every configured formatter option is supported by the tracked nightly; import grouping follows its default layout. Dependency requirements below one name a minor line with a reason, and the lockfile fixes the reviewed resolution. Silencing entire files or weakening the workspace tables to obtain a green run is rejected.

**Gate (Verification)** · `gate:lint:verification` The gate checks every member manifest except the unchanged upstream engine manifest for workspace lint inheritance without local lint tables and refuses tracked Cargo configuration containing rustflags or lint flags. The script `ci/measure_rustflags.py` reproduces the measured precedence of Cargo configuration over manifest lint settings. Its toolchain step enforces the nightly policy and records all four tool versions (`rec:toolchain:decision`). The nursery advisory enables both warnings and the nursery group; a scratch-crate regression witnesses a counted nursery warning. Workspace member paths under `vendor/` determine both Clippy exclusions and the Markdown census exemption, and a gate check requires the linter's vendor partition to match. The remaining checks cover formatting, first-party Clippy with warnings denied, workspace tests, the library without default features, the documentation and the linter. First-party printing and suppression checks operate outside vendor paths; controlled stream acquisition and exit are confined to named output-boundary items in cli-common and the child-byte relay in execwrap under (`rec:output:decision`); the prohibited-token check includes them. Test-configured items and files reached through test-configured module declarations are test trees and admit no suppressions.

**Amendment (Observation coverage)** · `amend:lint:observability` Add the proposed parsed coverage and runtime evidence gate (`proposal:observe:enforcement`), (`gate:observe:foundation`) in the foundation observability bite before domain implementation. Its smallest-item Justified exception form follows (`dec:lint:policy`), including the prohibition on file-wide and test suppressions. Labelled operation coverage, metric declarations and noninterference are obligations to check, not inferred from dependency declarations or a passing current gate. This amendment changes no existing compiler lint table.

**Amendment (Harness evidence matrix)** · `amend:lint:harness` Add the test-level, suite, implementation and execution-tier census of (`gate:harness:foundation`) to the foundation evidence work. The source/result join checks each first-party crate's unit, public-surface and integration levels, every declared conformance implementation and required service/performance result under (`rule:harness:tiers`); a fast-only run reports its remaining holds. Existing formatting, compiler, label, printing and suppression checks remain required, with no test or harness suppression exception. This amendment defines later gate work, not a newly implemented check.
